# Project 4 Classic public website

Static homepage, privacy policy, terms, and support for Gosh Apps' Project 4 Classic
desktop app and its optional Project4 Cloud Sync connection.

Published with GitHub Pages from the `main` branch root in
`goshitsarch-eng/project4-classic-site`:

- Homepage: https://goshitsarch-eng.github.io/project4-classic-site/
- Privacy: https://goshitsarch-eng.github.io/project4-classic-site/privacy/
- Terms: https://goshitsarch-eng.github.io/project4-classic-site/terms/
- Support: https://goshitsarch-eng.github.io/project4-classic-site/support/

There is no build step, JavaScript, sign-in, or OAuth callback on this website.
Keep Google client configurations, tokens, app source, and private projects out of
the public site repository. Publish only the contents of this directory. The app
repository remains private. The site uses the app's own Gosh Apps icon.

These public URLs are intended for Google Auth Platform's app-domain fields.
Publishing the website does not itself publish or verify the OAuth application.
Google controls OAuth production status and domain/branding verification.
