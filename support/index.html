Support

Help with the desktop app and its optional Google Drive connection.

Connect your computers

Open Tools → Cloud Sync and choose Connect Google Drive. Complete sign-in in your browser, using the same Google account on each computer. Use File → Open Synced Project to open a project from your library.

If your build asks for a Google desktop client configuration, import the desktop OAuth JSON supplied by the app owner. That is a one-time setup; the cloud connection itself is optional.

Offline changes and recovery

Your synced changes save locally before uploading. If the app reports Offline with pending changes, keep working and use Sync Now after your connection returns. If it reports Needs attention, review the explanation in Cloud Sync.

Competing project versions appear as separate copies in Open Synced Project. Use Cloud Sync → Recovery for earlier preferences, customizations, workspace, or attachment revisions.

Disconnect or remove data

Choose Tools → Cloud Sync → Disconnect to remove this computer’s saved sign-in credentials. This leaves your local files and cloud library intact. Review Privacy Policy → Retention, disconnection, and deletion for removing local and Google-held data.

Contact Gosh Apps

Open a support or privacy request in the website’s GitHub tracker. Include the app version, operating system, and a short description. A GitHub account is needed to submit a request.

The support tracker is public. Do not attach private projects, notes, personal files, passwords, OAuth tokens, or client secrets. For a privacy request, describe the question without posting the data itself.
